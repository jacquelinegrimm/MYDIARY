Views are my own. stk-blg 1: The Future vs. Weeknd I recently managed to build an incredibly simple, LLM-based system that was a 10x reduction in cost compared to an earlier, NLP-based system using a Databricks tool called ai_extract(). I strongly believe that every coding tutorial should start with something like: first off, message Mario and say, “excuse me, Mario, can you please set it up so I can use ai_extract()?” Then, while waiting, copy and paste the following into Databricks and fill it out with a prompt for your task and the columns of your input table. ai_extract/fill_in_extraction.txt The hype has worn off about LLMs, but I think that’s mostly because people were using it for its chatbot function, which is now non-functional. But we’re still in the future, where nearly every task costs 1/10th of what it used to five seconds ago. You can think of my task as, “hey, please read one billion pages of text for me in the next hour.” So everyone can reconnect with wonder: not only is that achievable, it’s achievable for 50 instead of 500 dollars.
